Aide-mémoire : commandes de base du terminal

Ce TP utilise principalement des commandes standard des systèmes d'exploitation de type Unix (Linux, macOS), qui sont les plus courantes dans le développement web. Cette fiche récapitule les fonctions de base du terminal (Bash/Shell), essentielles pour comprendre l'administration de serveurs.

Gestion des permissions (la plus critique)

La commande chmod est fondamentale pour l'administration de serveurs et l'hébergement.

CommandeSignificationRôle / utilisationExplication des permissions
chmodChange ModeModifie les droits d'accès (permissions) d'un fichier ou d'un répertoire.Les droits sont gérés pour 3 entités : User (Propriétaire), Group (Groupe), Other (Autres).
Valeurs octales(numérique)La permission est définie par la somme des droits R/W/X.
Exemple : chmod 444 index.html signifie : 4 (lecture) pour le Propriétaire, 4 pour le Groupe, 4 pour les Autres. Résultat : r--r--r--.		4 : r (lecture - Read)
2 : w (écriture - Write)
1 : x (exécution - Execute)

À retenir

Sur un serveur web, si le serveur n'a pas la permission de lecture (r) sur un fichier, il ne pourra pas l'envoyer au navigateur. Si le serveur n'a pas la permission d'écriture (w) dans un répertoire (ex : pour les uploads), l'opération échouera.
