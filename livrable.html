À déposer sur Moodle

Comment faire une capture d'écran ?
  • Windows : Windows + Maj + S, puis sélectionner la fenêtre de MobaXterm.
  • macOS : ⌘ + Maj + 4, puis Espace et cliquer sur la fenêtre du Terminal.

Les commandes tapées doivent être lisibles : agrandis la fenêtre si besoin, et ne fais pas clear avant la capture.
